# Memory Game

A browser-based memory game built with HTML, CSS, and JavaScript. Match pairs of cards featuring programming languages, frameworks, and developer tools.

## Project

- **Developer:** Jordana Perinotti
- **Course:** Construção de Páginas Web II
- **Project:** Final course project

## Technologies and Resources

- HTML, CSS, and JavaScript
- Phosphor Icons library for the interface icons
- Card images stored in the `images` folder

## How to Play

- Open `index.html` in a web browser.
- Choose a difficulty and select **Start game**.
- Flip two cards at a time and find all matching pairs.
- The game shows your time, attempts, and score when you finish.

## Difficulty Levels

| Level | Board | Pairs |
| --- | --- | ---: |
| Easy | 4 × 4 | 8 |
| Medium | 4 × 6 | 12 |
| Hard | 6 × 6 | 18 |

Your best score is saved in the browser. An internet connection is required to load the Phosphor icon font.
